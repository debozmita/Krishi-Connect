# 🌾 Krishi-Connect

> A unified digital agricultural ecosystem connecting farmers directly with buyers, equipment owners, and agricultural experts.

---

## 🚀 Overview

**Krishi-Connect** is a web-based prototype designed to solve critical challenges faced by small and marginal farmers in India. By eliminating middleman commission structures, providing localized equipment sharing, and offering expert diagnostic consultation, Krishi-Connect aims to maximize farmer profits and optimize yield.

---

## ✨ Key Features

* **🌾 Direct Farmer Marketplace:** Enables buyers to purchase fresh produce directly from farmers with zero middleman markup. Includes category filters (**Grains**, **Vegetables**) and live search functionality.
* **🚜 Equipment Rental Hub:** Allows local machinery owners to rent out tractors, harvesters, and tools hourly or daily, making modern technology affordable for small landholders.
* **👨‍🔬 Expert Advisory & Soil Diagnostics:** Connects farmers with certified agricultural specialists for soil health analysis and crop advisory.
* **📱 Responsive & Accessible UI:** Clean, intuitive visual interface designed for high readability across devices.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Flexbox & CSS Grid), JavaScript (Vanilla JS)
* **Design Systems:** Google Fonts (Poppins), Dynamic DOM Manipulation
* **Deployment & Version Control:** GitHub, GitHub Pages, GitHub Desktop
